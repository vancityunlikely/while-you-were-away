# 你不在的这一小时

一个单页离线作品：打开黄昏园子，点五个仍在发光的地方，读完这一小时留下的痕迹。

## 打开

直接打开 `index.html` 即可。为避免浏览器对本地媒体的限制，也可以启动本地静态服务：

```bash
python3 -m http.server 4174
```

然后打开 <http://localhost:4174>。

## 怎么玩

1. 点「走进去」。
2. 找到画面中的五个发光点。
3. 依次看完小屋、狐狸、灯、椅子和纸船留下的片段。
4. 当计数到 `5 / 5`，园子会交出最后一封信。

右上角「声 / 静」控制浏览器合成的夜间环境声。页面支持键盘 `Esc` 关闭当前卡片或信件。

## 结构

- `index.html`：页面结构与文案。
- `styles.css`：园子、热点、卡片和移动端布局。
- `app.js`：五个发现点、进度、环境声和完成信交互。
- `assets/`：主画面、五张特写和两段循环影像。

项目没有第三方运行依赖，不连接账号、分析或外部服务。

## 调试入口

- `?view=garden`：直接进入园子。
- `?view=letter`：直接查看完成信。
- `?view=cottage|fox|lantern|chair|boat`：直接查看对应发现点。
